# 合參 FATE ATLAS v3.11.0

正式網站：https://momopuke.github.io/judun-deploy/?v=3.11.0

## 本版
- 保留簡短答案，後接預設可見的完整解讀。各派依本次算出的線索逐一說明，共同提醒與不同側重用段落連起來。
- 流年採用生命靈數時，展開工作、感情、財運的生活應用，並可另外查看月份主題。
- 解讀正文、對照及細節區使用高對比配色。
- 單派與合參採同一版面，問題、答案、下一步與流派原圖集中在同一區。理由、提醒與各派依據集中在同一個展開區。
- 以轉職、創業、復合等常見問題提供具體生活例子。漫畫與人物故事採更自然的圖說。
- 恢復 12 張流派原圖。首頁選派和流派選單顯示縮圖，單派結果顯示原封面，合參結果顯示主導流派圖像。
- 結果頁顯示 11 套手繪三格漫畫。六爻採用已選定的「兔子與三枚銅錢」；其他流派各有場景與道具。
- 漫畫下方的線索、解讀與行動依本次結果更新。名人故事依主題與規則挑選，保留史料來源。
- 離線 HTML 報告保留本次線索、情境、行動與人物故事文字。
- 午夜紫藍、古金與星光配色，維持可讀的大字。
- 轉盤直接在首頁，桌機與合參入口並列；手機也不需展開。
- 頂部五個入口常駐。有子目錄時，桌機滑鼠懸停與鍵盤聚焦能展開；手機點箭頭展開，主按鈕仍可直接切頁。
- 開始分析時，按流派顯示約 2.2 秒的儀式彈窗：塔羅牌、銅錢、星軌、數字或四柱。可立即略過；減少動態模式縮短為 80ms。
- 轉場結束、略過或重複點按，都只執行一次計算／抽牌／起卦。
- 九組附來源的人物經歷，依本次象徵規則與題材選用，直接展開並解釋關聯。不宣稱人物命盤相同或經歷可驗證命理。
- 塔羅與起卦仍不索取生日；紫微缺資料不補造。單派流年依所選年份計算。

## 範圍
三步為選系統、填必要資料、看結果；儀式不是新增填表步驟。
出生資料在瀏覽器計算。馬雅只查曆法，不編造問事結果。
紫微未完成全盤流年飛化；八字未完成完整喜用神；六爻未完成完整用神旺衰與應期。各派範圍於畫面內說明。
多派權重只代表報告配置，不代表準確率。

## 部署與驗收
完整靜態網站，index.html 為入口；固定版本函式庫與授權隨附。
node qa-engine.cjs：引擎、日期邊界、流程、生活圖解及故事驗收。
node qa-mystic.cjs：動畫完成、略過、重複點擊、減少動態及錯誤回復。
Pages 自動發布 gh-pages；獨立驗收工作核對正式 HTTPS 每個資產的 SHA-256。
