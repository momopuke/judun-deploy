# 合參 FATE ATLAS v3.5.0

正式網址：https://momopuke.github.io/judun-deploy/

## 兩個主要入口

- 合參分析：選問題 → 生日 → 明確觸發抽牌／起卦（可略過）→ 各派對照 → 帶走建議。
- 單派體驗：按輪盤中央隨機選派；也能點扇區，或從「自己選流派」的圖像選單直接指定。選定後填生日，開啟同一派的解讀。

指定流派需要時辰卻未提供時，顯示資料不足並提供補資料；補完返回原流派。生日與互動在同一題返回時保留。隨機轉盤仍排除無法計算的命盤與僅作曆法參照的馬雅。

## 尺寸與互動

輪盤本體盡量填滿可用寬高；音效控制移到桌機標題區，保留圓盤下緣。手機圓盤接近滿寬。滑鼠指向單一扇區時，該扇區浮起放大20%，文字合計約放大50%；獨立預覽層保留穩定的點擊範圍，不縮放整個輪盤。移開恢復；轉動時清除預覽。觸控版直接點選或使用圖像選單。

首頁下方以換工作示意範例展示「問題 → 各派線索 → 共同方向、保留的提醒與下一步」，不另增加主要導航。範例清楚標示，不當成訪客本次結果。

## 解讀與資料範圍

使用本機題型、常見關鍵字與傳統象徵規則，並非無限制語意推理。依題型和輸入完整度配重；配重代表參照配置，並非準確率。缺資料不補造；數字同源的方法不獨立湊成共識，分歧保留。

流年使用所選年份的生命靈數個人年與塔羅年度牌；未實作完整紫微流年、八字喜用神或六爻應期。馬雅僅作曆法參照。

出生資料與問題不自動儲存；圖鑑進度、音效偏好留在本機。主動分享連結前提示包含本次資料。保存的HTML內嵌樣式並移除外部圖片依賴。
