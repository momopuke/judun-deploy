# 合參 FATE ATLAS v3.4.0

正式網址：https://momopuke.github.io/judun-deploy/

## 主要體驗

首頁分為兩個入口：

- 合參分析：選問題 → 填生日 → 自選抽牌／起卦 → 多派解讀 → 帶走建議。
- 轉盤選一派：填生日 → 隨機轉出可用流派 → 直接開啟該派解讀。

合參主線每一步有進度與返回；瀏覽器上一頁／下一頁保留所選模式。出生資料、圖鑑、命盤與手動配重皆可回到來源。首頁保留原本色彩、圖片與立體輪盤；手機頂部可直接跳到任一入口。輪盤依可用螢幕高度調整尺寸，指針和中央按鈕不被其他區塊遮住。實際轉動頁也使用相同尺寸保護。

抽牌、擲幣與梅花按問題實際選配，由訪客點擊觸發，可略過。返回不重抽；改題、改生日才清除事件。略過的系統自動排除並重分配權重。結果頁固定下一步，最後將同一份解讀的行動與觀察整理成帶走卡，提供完整 HTML 保存、分享與 PDF 列印。

## 檢查

執行 `node qa-engine.cjs`：567 項檢查，包括原有 12 系統、合參主線及單派轉盤模式；檢查數量不是命理準確率。

本版以 Chrome 桌機與 375px iframe 手機尺寸操作兩種入口，確認轉盤開啟單派結果、合參抽牌後生成多派報告、圖片與文字無橫向溢出、輪盤完整顯示。沿用已驗證的返回、出生資料編輯與保存流程；手機尺寸檢查未取代實體 iPhone Safari 驗收。

## 解讀範圍

依主題和常見關鍵字使用本機規則式解讀，不是無限制語意推理。流年使用所選年份的生命靈數個人年與塔羅年度牌；不冒充完整紫微流年、八字喜用神或六爻應期。資料不足不虛構。馬雅只作曆法參照。

缺少資料的系統不參與結論。生日數字同源的方法不單獨湊成跨來源一致；權重代表本次解讀配置，不代表準確率或證據強度。

出生資料與問題不自動儲存；圖鑑進度與音效偏好留在本機。主動分享連結會包含本次資料與問題，分享前有提示。全部執行依賴附在此包，無外部 CDN、登入或付費 API 需求。

## 檔案

- `index.html`、`app.js`、`journey.css`、`visual-refresh.css`：網站、兩種入口與解讀視覺。
- `interpretation-engine.js`：解讀規則與自動選配。
- 其餘固定版本引擎、樣式與 `assets/schools`：排盤、互動和原圖。
- `qa-engine.cjs`：可重跑檢查。
- `version.json`：正式資產 SHA-256 清單。
- `.github/workflows`：發布、回歸及正式 HTTPS 雜湊驗收。
- `UX-REVIEW.md`、`deployment-verification.json`：本版驗收與發布紀錄。

## 解讀排版 v3.4.0

深綠封面結合本題主參流派的代表照片，問題為小標、結論為主體；圖片不是本次計算出的命盤。建議與提醒緊接結論，跨派共同點或分歧集中在淡綠對照列。結論已包含的行動不再重複。各派依據、配重與流年月份按需展開。保留題型自動配重與離線保存；匯出報告移除外部圖片依賴。
