## 修正與驗收

整張報價的付款／保固／追加原文獨立保存，帶入辨識確認、核心分析、付費專題及報告，並拒用與已提供條款矛盾的缺漏結論。ProMax 限制同輪主要／備援路由與SDK疊加重試，保留成果並只補缺漏。

v1.2.129 正式驗收發現原自適應控制器不接受 timeout，造成五專題在發出模型請求前失敗；v1.2.130 以最小修改補齊逾時等待。原16項回歸、4項使用真實控制器的整合測試，以及2項套用／回退驗證通過。原首頁品牌、價差計算、付款與報告授權、營運資料及正式證據保留；新增的 document_terms 欄位只做加法遷移並納入到期清除。

兩個合成案件已實測上傳／確認／免費分析、Basic／ProMax 測試解鎖、解鎖後直接進入「看價差」、五個專題全部解鎖，以及完整／精華 HTML 與 PDF。報價3項、78000元；付款30/40/30、保固2年、追加書面確認均保留。完整PDF23頁、精華PDF7頁已核對文字與版面。原中斷案沿用3項精算接續五專題，服務紀錄本輪升級36.303秒；這是單案觀測，不是時間保證。

詳見 [v1.2.130 正式驗收紀錄](../validation/v1.2.130-acceptance.json)。付款仍為 TEST 模式，未真實扣款；SMTP未啟用，沒有真實寄信驗收。沒有在正式站刻意注入上游故障。
