## 如何整合進現有原始碼
這個專案是加密部署通道，**不是可編輯的 FastAPI 網站原始碼**。請在擁有現有正式站原始碼的環境中，將 `home-entry.css`、`home-entry.js` 加入既有靜態資產管理與版本化建置，並在首頁加上 CSS 和延後執行的 JS 引用：

```html
<link rel="stylesheet" href="<既有靜態路由>/home-entry.css">
<script defer src="<既有靜態路由>/home-entry.js"></script>
```

以上 `<既有靜態路由>` 是替換提示，非可直接貼用的 URL；不要新增未驗證的靜態路由。應在既有來源碼與測試環境合併，編譯後依原有 Ed25519 簽章、加密 payload、深度 SHA256 一致性流程發布。**不要**直接編輯 `channel/stable.json`，不得用未簽名包繞過發布閘門。

5. 若修改造成版面或功能倒退，直接回退兩個新增靜態檔的引用。
