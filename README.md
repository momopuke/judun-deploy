# 合參 FATE ATLAS v3.3.0

正式網址：https://momopuke.github.io/judun-deploy/

## 主要體驗

選問題 → 填生日 → 玩一下 → 看解讀 → 帶走建議。

每一步有清楚的下一步、進度與返回；瀏覽器上一頁／下一頁使用相同路由。出生資料、圖鑑、命盤與手動配重皆可回到來源。首頁沿用原本色彩、圖片與輪盤，輪盤的首頁按鈕進入主線；真正的隨機選派與圖鑑集中於「自由探索」。

抽牌、擲幣與梅花按問題實際選配，由訪客點擊觸發，可略過。返回不重抽；改題、改生日才清除事件。略過的系統自動排除並重分配權重。結果頁固定下一步，最後將同一份解讀的行動與觀察整理成帶走卡，提供完整 HTML 保存、分享與 PDF 列印。

## 檢查

執行 `node qa-engine.cjs`：553 項檢查，包括原有 12 系統與新主線；檢查數量不是命理準確率。

Chrome 桌機與 375px iframe 手機尺寸的五步流程、必填生日、可略過互動、抽牌及起卦、返回保留牌面、出生資料返回、圖鑑命盤返回、保存入口皆已操作。手機尺寸檢查未取代實體 iPhone Safari 驗收。

## 解讀範圍

依主題和常見關鍵字使用本機規則式解讀，不是無限制語意推理。流年使用所選年份的生命靈數個人年與塔羅年度牌；不冒充完整紫微流年、八字喜用神或六爻應期。資料不足不虛構。馬雅只作曆法參照。

缺少資料的系統不參與結論。生日數字同源的方法不單獨湊成跨來源一致；權重代表本次解讀配置，不代表準確率或證據強度。

出生資料與問題不自動儲存；圖鑑進度與音效偏好留在本機。主動分享連結會包含本次資料與問題，分享前有提示。全部執行依賴附在此包，無外部 CDN、登入或付費 API 需求。

- `UX-REVIEW.md`、`deployment-verification.json`：本版驗收與發布紀錄。

## 解讀排版 v3.3.0

保留五步導覽。解讀採單一主卡：一句結論、不同於結論的下一步、留意事項、精簡的跨派共同點或分歧。結論已含有的行動不再重複。各派只展示實際依據與說明，合併收進預設關閉的依據區；流年分項與月份按需展開。保留題型自動配重、原始資料及離線保存。563 項檢查。
