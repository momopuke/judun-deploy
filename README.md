# 合參 FATE ATLAS v3.0.0 — 解讀核心重寫

正式網址：https://momopuke.github.io/judun-deploy/

本版以解讀為主要內容。首頁新增主題與問題；計算後先顯示結論、實際依據、可用之處、盲點、不同面向的拉扯，以及可執行並可檢查的行動。原始命盤與算法移入次要區塊；完整報告也使用同一套解讀層。

## 實作方式

interpretation-engine.js 為可檢查的本機規則式解讀，不冒充即時大語言模型或專業命理師審盤。主題可選全面、事業、感情、財務、年度；自由文字會保留在解讀中，常見關鍵字可輔助選主題，但尚未提供任意自由問題的語意推理。建議是本站撰寫的現代情境轉譯，非古書原句或經實證驗證的預言。

六十四卦有各自的象義、風險與行動；本卦、之卦、動爻位置分開，不把之卦當作必然未來。78 張牌按牌位與正逆位處理，三張牌陣以現在牌作主錨點並串接背景與後續觀察。紫微按問題選擇相關宮位，八字使用實際十神，西洋分開太陽、月亮、上升與相關行星。靈數、九星及生日牌會保留不同數值或面向的拉扯，不硬湊同意。

## 範圍與未完成項目

馬雅只提供有算法依據的曆法位置，沒有可靠的個人判讀規則，因此不參與解讀輪盤，仍可在圖鑑查閱。完整出生資料可開啟 11 個解讀方法；沒有時辰時紫微再保留。

八字完整旺衰、格局、喜用神；紫微全盤三方四正、輔煞與流年飛化；六爻完整用神、旺衰、旬空、沖合、伏神、應期；以及逐卦逐爻原文與多動爻取法，尚未完整實作。各解讀頁明列限制，不將缺項假裝完成。印度採近似 Lahiri，不把中文二十八宿與印度二十七月宿直接等同。

## 驗收

執行 `node qa-engine.cjs`：509 項流程及資料檢查，包含原先排盤、DST、曆法、事件、分享與匯出；新增六十四卦對應、78 牌正逆位差異、牌位錨點、事業與感情情境差異、缺時辰保留、權重、問題文字跳脫等檢查。數量不代表預測正確率。

報告 HTML 自含解讀樣式；下載版展開各派解讀便於閱讀與列印。問題隨分享連結傳送時會先提醒；出生資料與問題未加入自動儲存。

圖片、輪盤與音效沿用現有設計。所有執行期依賴附固定版本，無外部 CDN、登入或付費 API 需求。完整原始碼、圖片、提示詞、回歸檢查及部署證據一併交付。
