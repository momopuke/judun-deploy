# 合參 FATE ATLAS · Observatory Edition v2.0.0

正式網址：https://momopuke.github.io/judun-deploy/
發布日期：2026-11-09（臺灣時間）

本版完成十二模組的輸入 → 計算／獨立事件 → 專屬圖譜 → 明細 → 報告流程；「十二模組可用」不等於涵蓋每個流派的所有技法，也不是命理預測經驗效度的證明。

## 主要變更
- 美學：墨綠黑夜、香檳金與象牙白；星盤主視覺、十二種圖形語言、分類篩選、獨立頁面與可關閉命盤明細。
- 西洋：Astronomy Engine 2.1.19 十顆行星、逆行、上升、MC、十二整宮宮界、五類主要相位、指定日行運對本命比較。
- 印度：近似 Lahiri 恆星黃道、南印度 D1、27 月宿／Pada、D9 Navamsa、Vimshottari 大運和平交點近似。
- 八字：出生時刻節氣月、四柱、藏干十神、按相鄰節點計算八步大運；明確採民用零時換日。
- 紫微：iztro 2.6.5 十二宮、14 主星、亮度、生年四化及大限；修正圖譜的固定地支宮位排列。
- 易經／六爻：獨立擲三錢六次、本卦與之卦、動爻、京房八宮、納甲、六親、世應與六神。
- 梅花：臺北曆時農曆年月日時起卦、互卦、變卦、體用；閏月沿用月序。
- 塔羅：完整 78 牌，單張、三張、塞爾特十字，正逆位與各牌位主題；生日牌與年度牌獨立呈現。
- 靈數／九星／馬雅：四頂峰與挑戰、節氣年月星與九宮示意、傳統卓爾金／Haab／長紀。
- 權重總和固定 100%；結果依權重排序，零權重模組退出報告主要結果。共識比較僅使用已標註的可比象徵來源，不替紫微或起卦硬造共識。
- HTML 自含樣式與 SVG；可由瀏覽器列印 PDF。分享包含座標與重複時刻選項，並保留原始抽牌／擲幣結果。

## 必要資料與計算邊界
- 僅生日：日期摘要、三柱（節氣交界保留）、靈數、生日牌、九星與馬雅曆。
- 十顆行星／印度月宿：需時間與 IANA 時區。上升／宮位另需緯度與經度；城市預設為市中心，可手動校正。
- 紫微與八字大運：另需傳統性別排盤參數。
- 夏令時間不存在時刻會拒絕排盤；重複時刻須選第一次或第二次。極圈地區不輸出不穩定宮位。
- 印度歲差為 J2000 Lahiri 錨點加歲差多項式的近似模型，非 Swiss Ephemeris；月宿、Pada、D9 與大運日期靠近交界須複核。Dasha 年長為 365.2425 天。
- 本版採整宮制；未加入 Placidus 等其他宮制。八字與紫微未校正真太陽時；八字喜用神、紫微流年飛化、九星日盤與旅行吉凶、其他印度分盤及其他流派分支均不宣稱已完成。
- 節氣交界：缺時辰時保留較寬不確定範圍；有時刻仍保留 0.02° 算法邊界。
- 起卦／抽牌必須獨立操作；分享 URL 含輸入資料，僅在使用者主動分享時揭露。

## 驗收
- 執行 `node qa-engine.cjs`：149 項 PASS，含 DST、出生 UTC、缺資料保留、地平線幾何獨立核對、64 卦、78 牌、四柱／大運、馬雅 epoch、權重、分享、HTML 匯出。
- 瀏覽器：十二張命盤明細逐張開關通過；出生時地 → 十顆行星／紫微排盤 → 報告通過；三錢、梅花與十張牌操作通過。
- 手機：390px 容器（375px 實際內容寬）無橫向溢出；標題換行與主視覺已檢視。
- 正式 HTTP 與資產 SHA-256 由發布 workflow 部署後核對，結果見 deployment-verification.json（交付包內）。

## 使用與部署
`index.html` 為入口，其餘 CSS/JS 置於同資料夾。可用 `python3 -m http.server 8000` 啟動本機，正式部署使用 HTTPS。
所有執行期依賴已附帶固定版本，沒有外部 CDN、登入或付費 API 需求。共用來源程式碼見 GitHub gh-pages 分支；MIT 供應商版權保留在原始檔與 iztro-LICENSE.txt。
