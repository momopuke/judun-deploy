# 合參 FATE ATLAS v3.7.1

正式網站：https://momopuke.github.io/judun-deploy/

## 本版變更
- 頂部直接顯示首頁、選算命系統、本次解讀、自由探索、出生資料；桌機與手機皆不需展開更多。
- 暖奶油色、柔和漸層與精緻圖案；移除固定人物漫畫。
- 首頁清楚區分「幫我合參」與「自己選系統」；12 個系統直接點選，隨機輪盤收為選用。
- 主要流程只有選系統、填資料、看結果。合參按下分析後，一併完成所需獨立抽牌／起卦。
- 單派結果改成完整頁面；首屏顯示重點、實算依據和提醒，生活例子、詳細計算可展開。
- 塔羅、易經、六爻、梅花不要求生日；紫微缺必要資料時留在可補填的位置。
- 看完可換派，保留出生資料；瀏覽器上一頁恢復原系統結果。
- 生活解讀使用本次計算的規則、數字、星曜、卦象或牌面，不再只按問題主題套同一故事。
- 名人只在系統、實算象徵及題材吻合時顯示，沒有吻合就省略；附來源與比較範圍。
- 單派生命靈數流年與塔羅年度牌依所選年份計算。

## 使用與範圍
直接開啟網站即可。無登入需求，輸入只在瀏覽器計算。
生日不完整不會補造出生時間；缺時辰只顯示有依據的日期摘要。
馬雅保留為曆法查詢，不編造人格或問事結果。
各派權重代表報告配置，不代表準確率。人物經歷不作命盤驗證。
現有引擎仍各有範圍：紫微未完成全盤流年飛化；八字未作完整喜用神判斷；六爻未完成用神旺衰與應期推斷。畫面內可展開範圍。

## 部署與驗收
完整靜態網站，無建置依賴；index.html 為入口。
固定版本的天文、紫微等函式庫隨附，保留授權。
執行 node qa-engine.cjs；版本資產雜湊列於 version.json。
Pages 自動發布 gh-pages；獨立驗收工作檢查引擎、流程及實際 HTTPS 全資產雜湊，避免雙重部署。
